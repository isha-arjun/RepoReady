
# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in RepoReady, please report it privately rather than posting sensitive details in a public issue.

If private vulnerability reporting is enabled, use the repository's **Security** tab on GitHub to submit a report.

Otherwise, contact the repository maintainer through an appropriate private communication channel.

Please include:
- A description of the suspected vulnerability.
- Steps to reproduce it, if available.
- The potential impact.
- Relevant screenshots or examples, if safe to share.

Never include passwords, access tokens, or other secrets.

## Response

RepoReady is an early-stage project. The maintainer will make a reasonable effort to review reports, but response times and fixes are not guaranteed.

## Scope

This policy covers security issues in RepoReady itself, not vulnerabilities in GitHub or unrelated services.
